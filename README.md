# ⚡ StockVerse Pro — Financial Intelligence Terminal

StockVerse Pro is a sleek, modern, glassmorphism-inspired web app built using Streamlit. It provides real-time tracking for Indian Stock Market benchmark indices (NSE), portfolio analytics, wealth compound growth forecasting, and delivery tax estimations.

---

## 🔥 Features

* **🌐 Market Dashboard**: Live tracking for major Indian benchmark indices (NIFTY 50, SENSEX, BANK NIFTY, NIFTY IT) along with a key stock watchlist.
* **💼 Portfolio Tracker**: Add and manage custom stock holdings with real-time valuation and live profit/loss breakdown.
* **🍕 Capital Allocation**: Interactive visual allocation charts for holdings spread distribution.
* **📈 Trend Analyzer**: Clean 6-month historical price trend curves powered by Plotly.
* **🧮 Return & Tax Estimator**: Calculate CNC delivery taxes (STT, Exchange Charges, GST, SEBI fees) and forecast future wealth compound return (CAGR).

---

## 🛠️ Tech Stack

* **Frontend/Framework**: [Streamlit](https://streamlit.io/)
* **Data Source**: [yfinance](https://pypi.org/project/yfinance/)
* **Data Processing**: [Pandas](https://pandas.pydata.org/)
* **Visualization**: [Plotly Express](https://plotly.com/python/plotly-express/)
